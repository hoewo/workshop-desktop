# Workshop · 三个交互升级方案

> Status: draft · 前端原型 · 非已接受项目事实
>
> 三个方案基于 `design/` 原稿改造，分别从「用户执行路径」出发做体验升级。范围递增，不互斥。纯 vanilla HTML/CSS/JS，无构建，双击 `index.html` 可跑。三份各自独立，互不依赖。

## 共同基底（三方案都改）

原稿问题诊断的根因：**UI 布局与路径价值倒挂**——低价值的状态展示铺在首屏黄金位，高价值的"快记/检索/治理 AI 上下文"被藏起来。三方案都先做这几件地基事：

- **omnipresent 快记**：顶栏常驻输入框，回车即记到当前活跃项目，零选择。桌面应用知当前前台 cwd，不该让用户每次记一笔都选项目。
- **全文搜索**：记录池顶部加搜索框（标题+正文+标签）。原稿讽刺的是 `record.search` 是 AI 取用路径——AI 能搜，人却不能搜。
- **时间倒序 + 全量滚动**：`when` 改可排序时间戳，列表默认倒序；`PAGE_SIZE` 从 3 改 20，记录是流式内容不该 3 条分页。
- **AI 活动 / metrics / Codex 状态降级**：从首屏平铺收进次要区（方向一收悬浮，方向三进右栏），把空间还给记录列表。
- **用户语言重命名**：取用→AI 用过、注入落点→对应文件夹、origin=human/agent→我记的/AI 记的。删掉 push/pull/CLI/MCP/D-008 等架构黑话外暴露。
- **详情页 meta 重构**：原 8 格 schema 字段平铺 → 一行叙事（"AI 记的 · workshop-desktop · 今天 · AI 用过 2 次"）。
- **键盘层**：⌘K 搜索、⌘N 新建、ESC 关 modal、j/k 浏览。
- **记录生命周期**：可标记过时/归档，过时默认从主列表隐藏仍可搜到（避免 AI 取用到垃圾结论）。

## 三个方案

| | 方向一 `design_1_local` | 方向二 `design_2_synergy` | 方向三 `design_3_loop` |
|---|---|---|---|
| 主题 | 人本地基 | 人机协同 | 全闭环 |
| 路径 | A 快记 + D 检索 + 生命周期 | + B 上下文控制台 | + C turn 卡片可干预 |
| 北极星 | 人愿意记、找得到 | 人能治理哪些给 AI | 人机回合，闭环可追溯 |
| 首屏焦点 | 记录池（AI 活动收悬浮） | 同左 + AI 可见条 | 三栏：项目/记录/AI运行流 |
| 新增能力 | 搜索/时间序/快记/过时 | pin 必带、mute 不给AI、临时勾选注入集、反向链 | turn 卡片、追问/补充/存疑、闭环流程图 |
| 约束处理 | 不碰后端 | pin/mute/勾选纯客户端 mock（守 D-008） | 同左，回应追加为人记记录 |

### 方向一 · 人本地基（`design_1_local/`）

**回答**：人不愿意记、记了找不到，一切免谈。先把纯人的体验地基打牢。

- 顶栏 omnipresent 快记，回车即记，⌘↵ 多行，⇧↵ 切归属
- 记录池搜索 + 时间倒序 + 全量滚动
- AI 活动（取用流/上次运行）收进右下角悬浮，默认收起
- 记录可标记过时，默认隐藏仍可搜到
- 详情页 8 格 meta → 一行叙事

### 方向二 · 人机协同（`design_2_synergy/`）

**回答**：人是地基，但产品差异化在 AI 闭环。补"人能治理哪些记录给 AI"——不只是可见性，是掌控感。

- 项目切片下显示「AI 可见 N 条（必带 M · 不给 AI K）」，可展开预览
- 记录标记 **pin 必带**（下次该项目 AI 任务强制注入）/ **mute 不给 AI**（仅人可见，取用出口排除）
- **临时勾选注入集**：人手动干预一次注入的上下文（客户端只标选，不派发运行 · 守 D-008）
- 闭环反向链：人记记录详情页加「AI 用过这条」——列出取用过它的运行 + 产生的回写
- metric 衡量人持续供给（AI 可见/必带/不给AI 计数）

### 方向三 · 全闭环（`design_3_loop/`）

**回答**：闭环不只被动接收，要能干预。把取用流从"事件列表"改成"turn 卡片"，人看完结果能追问/补充/存疑。

- 布局改三栏：项目 / 记录池 / AI 运行流（常驻右栏）
- 取用流改 **turn 卡片**：一张卡 = turn 编号 + 时间 + 取用了哪几条 + 写回哪条 + 结论摘要，卡片内流向线「取用 → 写回」
- 顶部闭环迷你流程图：记录 → 运行 → 回写
- turn 卡片可 **追问 / 补充 / 标记存疑**：追加为新人记记录，自动关联该 turn（闭环又多一条反向链：人→AI结果→人的新思考）

## 与已接受决策的关系

- 不修改 D-003/D-008/D-011/D-014/D-017/D-018/D-019 任何 accepted 决策。
- pin/mute/勾选注入集/turn 回应 均为**客户端 UI 可视化 + mock**，不改 app server 权限面、不派发执行（守 D-008）。
- 脱敏边界仍由 app server 取用出口实现，客户端仅预留入口。

## 运行方式

三个目录各自独立，双击对应 `index.html` 即可在浏览器打开。数据为内联 mock，仅演示交互形态。各目录附 `preview.png` 为初始渲染截图。
