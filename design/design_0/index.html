注入命中与取用

注入（push · 客户端→编程工具）：用户点"发送"时，buildCodexUserInput 把当前记录结论片段塞进 Codex prompt，一次性组装。数据源 codex-runs/index.json（D-009）。
取用（pull · 编程工具→记录池）：编程工具执行任务前主动检索记录池，查是否有相关历史、决策、上下文。通过 record.search RPC 实现（搜 title + body 正文）。MCP 适配外部 Agent（Claude Code 等）为后续扩展。数据源：取用日志 record-searches/index.json（独立于 codex-runs）。
安全模型：读开放——注入路径已接（数据源 codex-runs）；取用路径通过 record.search 实现（agent token 可调用，搜 title + body 正文）。写收紧：agent 受限 token 只能 record.create，改写正文走 D-011 确认页。客户端不派发执行动作（D-008）。
遥测边界：注入/取用次数是派生展示，不存进记录本体（守 D-014/D-016/D-009），不升级记录类型系统。
