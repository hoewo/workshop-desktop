## 文件职责

- `docs/project-plan.md`：短入口和更新规则。
- `docs/project/current.md`：active core，只放当前焦点、当前候选 Goal/Iteration、当前任务顺序和开放决策。
- `docs/project/context.md`：项目事实、代码事实来源和当前约束。
- `docs/project/backlog.md`：原料池，不直接执行。
- `docs/project/goals.md`：Goal 和 Goal Intake。
- `docs/project/scopes.md`：Goal 范围边界和风险控制。
- `docs/project/iterations.md`：Iteration 计划和验收入口。
- `docs/project/tasks.md`：当前 Iteration 任务清单。
- `docs/project/reviews.md`：Review 模板和完成后的评审记录。
- `docs/project/decisions.md`：accepted Decisions 和 open Decision Candidates。
- `docs/project/roadmap.md`：now / next / later / not_now 排序。
- `docs/project/indexes/`：导航和 ID 查询，不作为事实源。
